# Pokémon Pokopia — Tradução PT-BR

Tradução para português do Brasil de **Pokémon Pokopia**, revisada por **protonnegativo**.

Baseada na tradução comunitária de [LucianoNeo](https://github.com/LucianoNeo/pokemon-pokopia-pt-br) (v2.5.0), com correções de texto e nova tela de título.

> 🇺🇸 Brazilian Portuguese translation for Pokémon Pokopia. Download the zip from Releases, drop the folder into the game's mod folder and enable it.

## Download

Vá em **[Releases](../../releases/latest)** e baixe `Pokopia-Traducao-PT-BR.zip`.

## Como instalar

1. **Extraia** o zip.
2. No emulador (Eden, Eglantine ou outro baseado no yuzu), clique com o botão direito no Pokopia >
   **Abrir local de mods**.
3. **Arraste** a pasta `Traducao PT-BR protonnegativo` para lá.
4. Em **Propriedades > Add-ons**, deixe o mod **ativado**.
5. Nas **Propriedades > Sistema** do jogo, use o idioma **Inglês (EUA)**: a tradução substitui o inglês.

Se você já tem outra tradução PT-BR instalada, **desative a outra**. As duas substituem os mesmos arquivos.

## Bom saber

- Para o jogo **2.0.1 / 2.0.1a**.
- Funciona junto com o mod de ícones de botão (Steam Deck / Xbox / PlayStation).
- O que mudou em relação à base está nas notas de cada [Release](../../releases).
